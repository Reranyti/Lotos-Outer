# Нормальная_ветка (внутреннее)

Скрытый путь, включаемый из нейтральной ветки точной непрерывной цепочкой смертей (см.
`NormalBranchDeaths`). Порядок и условия описаны только в этих исходниках — игроку нигде на неё
не указывают. Реальное название ветки в коде и публично НЕ пишем.

## ВНИМАНИЕ: ветка НЕ безопасна, пока не проверена досконально

Это незавершённая и не проверенная до конца ветка. НЕ вливать в `main` и НЕ включать в релиз/сборку,
пока каждый шаг не протестирован вручную на реальном ПК:

- цепочка смертей (строгий порядок, сброс, закрытие при выборе ветки);
- сцена входа (к воде → удушение → подъём → бордовый залив → телепорт) — на разных мирах и в
  мультиплеере;
- пустое измерение `hollow` (вход/выход, респавн, сохранение);
- самоблокировка `NormalBranchLock` (мод «умирает» до переустановки) — проверить, что миры грузятся,
  блоки не пропадают, а свежий jar снимает блокировку. Ничего не удаляется; реальное удаление файлов —
  только через опциональный аддон Consequences, тестируется отдельно на своём ПК.

Пока всё это не проверено — считать ветку небезопасной.
