# LotusLib API

LotusLib — отдельный библиотечный JAR для расширений Lotus Blight и совместимости с большими сборками Forge 1.20.1.

## Артефакты

| Файл | Назначение |
|---|---|
| `lotuslib-1.0.0.jar` | Общие классы очередей, интеграций, спецификаций версий и API расширений. |
| `lotusblight-1.0.0.jar` | Основной контент Lotus Blight: заражение, лотосы, биомы, книга, карта, мимики и Лотонирия. |

Оба JAR должны находиться в папке `mods`. Lotus Blight использует классы из LotusLib, поэтому для полной установки нужны оба файла.

## Необязательные интеграции

Интеграция должна проверять наличие нужного `modid` через `LotusIntegrationManager`. Если мод отсутствует, адаптер не регистрируется, а Lotus Blight продолжает работать в базовом режиме. Прямые импорты классов чужих модов в основном ядре запрещены: адаптеры должны использовать безопасные точки расширения и проверку версии.

`LotusIntegrationSpec` хранит идентификатор мода, минимальную и максимальную версию, приоритет и признак необязательной зависимости. При повторной регистрации менеджер оставляет адаптер с более высоким приоритетом.

## Производительность

`LotusTaskQueue` ограничивает количество тяжёлых задач за тик. Генерация природных очагов не должна выполняться непосредственно внутри критического события генерации чанка. Чанк только добавляет лёгкую задачу, а поиск воды и создание очага выполняются позже ограниченными порциями.

Активная учебная зона первого игрока составляет 32 чанка. Это не ограничивает глобальное распространение уже созданных очагов. В радиусе учебной зоны мод ищет настоящую воду, а при её отсутствии создаёт небольшой безопасный пруд.

## Правила совместимости

Интеграции не должны заменять блоки или биомы других модов без проверки. Дополнительный контент регистрируется в собственном namespace `lotusblight`, а worldgen должен использовать ограниченные очереди и проверять уже загруженные чанки, чтобы не создавать каскадную загрузку мира.
