# Lotos Studio

Локальная программа для работы над модом. Запускается как сайт на `127.0.0.1` (наружу ничего не уходит), нужен только Python.

**Запуск:** двойной щелчок по `run.bat`, откроется браузер. Остановить: закрыть чёрное окно.

## Что внутри

**Эпизод** (раскадровка). Кадры с местом, героями, камерой, светом, звуком, текстом и референсами (свои рисунки и скриншоты, можно вставить из буфера). Справа схема кадра и «Как я это понял»: пересказ словами, который можно подтвердить (✔) или отправить на переделку (✖). Автосохранение и история версий. Каждое сохранение выгружается в `art/episodes/<эпизод>.md` и `.json`, оттуда Claude читает твою раскадровку.

**Проверка.** Без запуска Minecraft: компиляция шейдера, прогон шейдера на скриншотах (до/после), кадры сцены 13-й концовки, установка шейдер-пака в игру.

**Панель мода.** Сборка, копирование jar в `mods`, git (что изменилось, коммит, отправка), свободное место на дисках.

**Логи.** `latest.log`, последний вылет, лог лаунчера, с фильтром.

**Состояние.** Что программа нашла (Java, проект, `.minecraft`) и какие пути использует. Свои пути: `data/config.json`.

## Полезно знать

- F3+R в игре перезагружает шейдеры без перезапуска.
- Данные программы (`data/`) в git не попадают, раскадровка попадает через `art/episodes`.
