# Идеи и потенциальные зависимости — ночной проход (2026-09-17, ~01:20)

Один сфокусированный проход по исследованию, не бесконечный опрос всю ночь (экономим токены
по просьбе пользователя). Ничего отсюда не реализовано — это just заметки на будущее.

## Потенциальные зависимости

### TerraBlender — качество размещения биомов
https://modrinth.com/mod/terrablender

Библиотека именно для добавления биомов "простым и совместимым способом". Сейчас мы регистрируем
`lotus_marsh`/`blessing_tundra` через `BiomeManager.addAdditionalOverworldBiomes(...)` — это
старый/грубый способ (базовый Forge API), который просто вставляет биом в общий пул с
фиксированным весом, без тонкого контроля над климатическими регионами и без явной совместимости
с другими крупными ворлдген-модами (Terralith, Biomes O' Plenty и т.п. — они тоже используют
TerraBlender, и наши биомы через голый BiomeManager могут конфликтовать/перекрываться с ними
менее предсказуемо).

**Что это даст:** более контролируемое распределение — например, гарантировать, что
`lotus_marsh` тяготеет к низинам/рекам, а `blessing_tundra` — к холодным регионам, а не просто
"иногда где-то вставляется". Плюс лучшая совместимость, если пользователь однажды добавит другой
крупный ворлдген-мод.

**Статус:** не подключено. Требует переписать регистрацию биомов (`LotusBlight.java`,
`ModBiomes.java`) на `Region`/`RegionType` API TerraBlender вместо `BiomeManager`. Средний объём
работы, не критично для текущей версии.

### Curios API — рассмотреть для "линзы ясновидения"
Не проверено детально в этом проходе, только гипотеза: `lotus_seer_lens` сейчас — разовый
расходуемый предмет (юзается один раз, даёт постоянный флаг). Если вместо этого сделать её
надеваемым аксессуаром через Curios (слот амулета/кольца), можно было бы завязать эффект на
реальное **ношение** предмета, а не на факт использования один раз в прошлом — например, "видишь
скрытые очаги только пока линза надета" вместо "увидел один раз — и навсегда". Это меняет баланс
(предмет становится ценным активным выбором слота, а не одноразовым бустом). Не проверял, ставит
ли Curios API реальную сложность интеграции — оценить в следующий заход.

## Идеи по развитию мода (геймплей/контент)

1. **Финальное ядро/концовки** — самый важный открытый вопрос из `DESIGN_V2.md` (раздел 6, п.2)
   всё ещё не решён: что физически представляет собой финальный источник Мирового Лотоса,
   определяющий выбор между "уничтожить" и "присоединиться". Без этого решения нет реального
   финала игры, а `LotusGraftingRodItem`/`joinedLotus`-флаг существуют без цели, к которой ведут.

2. **Структура "Объект Ноль"** — сейчас это просто точка спавна без структуры (по решению
   пользователя), но можно рассмотреть минимальную декоративную деталь на будущее: например,
   табличка/маркер с лором при первом появлении, без полноценного здания — усилило бы ощущение
   "прибытия учёного", не противореча решению "без структуры".

3. **Звук** — у мода сейчас нет ни одного кастомного звука (все `SoundEvents.*` — ванильные,
   переиспользованные не по смыслу: например, `GENERIC_EXPLODE` при переходе фазы, `GRASS_PLACE`
   при цветении). Пара тематических звуков (мягкий "вздох" цветения, зловещий гул Сердца) сильно
   поднимут атмосферу дёшево — не нужен композитор, можно взять свободные CC0-сэмплы.

4. **Достижения** — уже 12 штук реализовано, но можно рассмотреть скрытую цепочку под концовку
   "присоединиться" отдельно от "уничтожить" (сейчас у обеих концовок нет отдельного трекинга
   достижений вообще).

5. **Датапак-балансировка** — `LotusConfig` уже даёт in-game экран через YACL, но было бы полезно
   вынести таблицы `SpreadTables`/`InfectionPhases` (пороги фаз, радиусы) в datapack-JSON вместо
   хардкода в Java — тогда игроки/сборки смогут тюнить баланс без пересборки мода. Существенный
   рефакторинг, не для быстрого захода.

## Не проверено / требует отдельного захода

- Точная стоимость интеграции Curios API (сложность, версия под 1.20.1 Forge).
- TerraBlender: конкретный API вызовов под Forge 1.20.1 (какая версия TerraBlender, как выглядит
  `Region`/`RegionType` регистрация) — не проверялось байткодом/докой в эту сессию.
